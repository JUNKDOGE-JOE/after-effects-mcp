# Composition settings capability

Composition settings are served through the public CEP host MCP surface. The
native path is reserved for the frozen AEGP primitives; maintained scripting
semantics use `ae_exec`.

Acceptance is one disposable After Effects fixture exercised through the
public tool, with before/after state, typed provenance, audit evidence, and a
verified Undo for writes. Keep schemas and generated native protocol files in
their checked-in host/native locations.
